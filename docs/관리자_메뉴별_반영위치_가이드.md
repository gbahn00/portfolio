# 관리자 메뉴 → 실제 사이트 반영 위치 가이드

기존 `관리자_사용설명서.md`가 "이럴 땐 이렇게 하세요" 방식이라면, 이 문서는 **왼쪽 메뉴 순서 그대로** 훑으면서 "이 메뉴에 입력한 내용이 실제로 사이트 어디에 나오는지"를 정리한 지도입니다. 코드를 직접 확인해서 정리했기 때문에, 일부는 예전 문서 내용과 다를 수 있습니다(특히 "공개 상태" 관련 — 아래 참고).

**⚠️ 표시가 붙은 항목은 지금 입력해도 방문자 화면 어디에도 나타나지 않습니다.** 잘못 입력한 게 아니라, 아직 화면과 연결이 안 되어 있는 상태입니다. 나중에 필요해지면 알려주시면 연결해 드릴 수 있습니다.

---

## 0. 사이트 전체 그림

**홈페이지(`/`)** 는 정확히 7개 구역이 이 순서로 고정되어 있습니다(관리자 화면에서 순서를 바꿀 수 없습니다):

1. 대표 화면 (Hero)
2. 프로필 — "소개" / "핵심 수치" / "업무 역량" 3개 탭
3. 업무 성장과정
4. 대표 프로젝트 (목록, 최대 8개 — Design 4개 + Content 4개)
5. 향후 추진 계획 (최대 3개 카드)
6. FAQ
7. 마무리 화면

**프로젝트 상세 페이지(`/projects/프로젝트ID`)** 는 "대표 프로젝트" 목록에서 프로젝트를 클릭했을 때 열리는 개별 페이지입니다. 순서는: 대표 화면 → (보정 전·후 비교, 또는 비교 사진이 없으면 대체 이미지/영상 + 프로젝트 개요·제작 의도·기여도·Tools) → 결과물 영상 → 상세 이미지 → Contents → 이전/다음 프로젝트.

## 1. 대시보드 (`/admin`)

입력하는 화면이 아니라, 전체 항목 개수를 요약해서 보여주는 첫 화면입니다.

---

## 2. 프로필 관리 (`/admin/profile`)

→ 홈페이지 "프로필" 구역의 **"소개" 탭**과 **"핵심 수치" 탭**을 함께 관리합니다.

- 이름 / 소속 / 직급 / 직무 / 입사일 — "소개" 탭에는 직접 안 보이고, 사이트 다른 곳(시작 화면 등)에서 재사용될 수 있는 기본 정보입니다.
- 짧은 자기소개 / 긴 자기소개 — ⚠️ 현재 "소개" 탭 화면에는 표시되지 않습니다(대표 문구·문단·키워드만 표시됨).
- 대표 문구 — "소개" 탭 맨 위 큰 문구.
- **"소개 탭 본문 (문단·키워드)"** 박스 — 이 문단·키워드는 사실 "핵심 철학 관리" 메뉴와 **같은 데이터**입니다. 앞쪽 문단 2개만 화면에 보입니다. ⚠️ **주의**: "핵심 철학 관리"에서도 이 문단·키워드를 똑같이 고칠 수 있어서, 두 메뉴를 번갈아 쓰면 나중에 저장한 쪽이 이전 수정을 덮어씁니다. 가능하면 이 두 항목은 "핵심 철학 관리" 메뉴 한 곳에서만 수정하는 걸 권장합니다.
- 프로필 사진 — "소개" 탭 사진.
- 촬영 현장 사진 — 같은 "소개" 탭의 사진 스트립.
- 주요 정보(항목명/값) — "핵심 수치" 탭의 숫자·라벨 카드.
- Skills(도구 이름·숙련도 %) — "핵심 수치" 탭 하단 세로 진행바. 도구 이름은 정해진 목록(Photoshop/Premiere Pro/Illustrator/After Effects/CapCut/생성형 AI) 중에서만 골라야 아이콘이 붙습니다.

---

## 3. 시작 화면 관리 (`/admin/hero`)

→ 홈페이지 맨 처음 "대표 화면"(Hero) 전체.

- 핵심 문구 / 보조 문구 — 첫 화면 큰 글자·보조 문장.
- 이름 / 직무 / 소속 / 입사 연도 표기 / 배지 문구 — 첫 화면 하단 메타 정보.
- 대표 영상(선택) / 대표 이미지 — 첫 화면 배경. 영상이 있으면 영상이 재생되고, 재생이 안 되는 환경(또는 영상 미등록 시)엔 이미지가 대신 나옵니다.
- ⚠️ 상단의 "시작 화면 노출" 체크박스와 "공개 상태" 드롭다운은 현재 실제 화면에 반영되지 않습니다 — 지금 코드에서는 이 값과 관계없이 대표 화면이 항상 보입니다. (프로젝트의 "공개 가능 여부"·"공개 상태"는 이것과 별개로 실제로 작동합니다 — 6번 참고.)

---

## 4. 핵심 철학 관리 (`/admin/philosophy`)

→ 홈페이지 "프로필" 구역의 **"소개" 탭** 안, 대표 문구 아래 문단·키워드(2번 "프로필 관리"와 같은 데이터).

- 문단 — 앞 2개만 화면에 보입니다(3개 이상 넣어도 무방하지만 3번째부터는 안 보임).
- 키워드 — 최대 5개까지 화면에 보입니다.
- ⚠️ "제목" 입력란은 현재 어디에도 표시되지 않습니다.
- ⚠️ "영역 노출" 체크박스와 "공개 상태"도 현재 반영되지 않습니다(문단·키워드는 항상 보입니다).

---

## 5. 성장과정 관리 (`/admin/timeline`)

→ 홈페이지 "업무 성장과정" 구역.

- 맨 위 "성장과정 제목" — 이 구역의 큰 제목.
- 연도별 항목(연도/제목/설명/주요 경험/전달 메시지/대표 이미지·영상) — 연도별 카드. 카드 하단 "영역 노출" 체크박스를 꺼두면 그 연도 카드만 화면에서 빠집니다(전체 구역 자체는 항상 보임).
- 순서는 각 항목 옆 ↑↓ 화살표로 바꿉니다.

---

## 6. 프로젝트 관리 (`/admin/projects`)

→ 홈페이지 "대표 프로젝트" 목록 + 프로젝트를 클릭했을 때 열리는 개별 상세 페이지(`/projects/...`) 전체.

목록 화면에서:
- "+ 새 프로젝트"로 추가, 각 프로젝트 옆 ↑↓로 순서 변경(맨 앞 8개만 홈페이지에 노출 — 앞 4개 Design 칼럼, 다음 4개 Content 칼럼).
- **"공개 가능 여부(클라이언트 승인)"를 켜야만** 그 프로젝트가 홈페이지 목록과 상세 페이지 어디에도 나타납니다. 꺼져 있으면 완전히 숨겨집니다(이건 실제로 작동합니다).
- ⚠️ "대표 작업으로 지정" / "대표 프로젝트 상세 사례로 지정" 토글은 현재 목록 화면에 작은 라벨(태그)만 보여줄 뿐, 실제 홈페이지 노출 여부·순서에는 영향을 주지 않습니다(노출 여부는 위 "공개 가능 여부"와 순서 화살표만으로 결정됩니다).

프로젝트를 클릭해 들어간 편집 화면에서 (필드 → 상세 페이지 위치):
- 프로젝트명 / 브랜드명 / 작업 분야 / 제작 연도 / 프로젝트 번호 — 상세 페이지 대표 화면 상단.
- 제작 의도 → "제작 의도" 섹션. 기여도(담당 역할) → "기여도" 섹션. 상세 설명 → "프로젝트 개요" 섹션. Tools → "Tools" 섹션.
- 대표 이미지 — 상세 페이지 대표 화면 배경. (아래 "목록 미리보기"·"보정 전후 대체 이미지"가 비어 있으면 이 사진이 자동으로 대신 쓰입니다.)
- 목록 미리보기 이미지/영상 — 홈페이지 목록에서 그 프로젝트 행에 마우스를 올렸을 때 뜨는 작은 미리보기. 비워두면 대표 이미지 → 그래도 없으면 상세 이미지 갤러리 첫 장이 대신 쓰입니다.
- ⚠️ 미리보기 영상 — 현재 어디에도 표시되지 않습니다(예전 "대표 상세 사례" 화면용으로 만들었던 필드인데, 그 화면 자체가 지금은 쓰이지 않습니다).
- 최종 영상 — 상세 페이지의 "결과물 영상" 큰 단일 블록.
- 상세 이미지·영상(갤러리) — 상세 페이지 "상세 이미지" 구역(자동으로 좌우 반복 스크롤).
- Contents(영상 전용) — 상세 페이지 "Contents" 구역. 마우스로 드래그해서 넘겨보는 영역이며, 영상이 화면에 다 들어갈 만큼 적으면 드래그 안내(Drag 배지)가 안 뜹니다.
- 보정 전·후 비교 — 상세 페이지 "보정 전·후" 구역. 각 비교쌍에 "구분"을 디테일컷/모델컷으로 지정하면, 두 종류가 하나씩이라도 있을 때 자동으로 "디테일컷 | 모델컷 | 프로젝트 개요~Tools" 3단 구조로 바뀌고, 두 그룹의 사진 넘기기가 서로 독립적으로 동작합니다. 구분을 안 하면 지금처럼 구분 없는 단일 슬라이더입니다.
- 대체 이미지·영상(선택) — 보정 전·후 비교가 하나도 없을 때만 그 자리에 대신 나타납니다. 비워두면 대표 이미지가 자동으로 대신 쓰입니다.
- 성과 수치 — ⚠️ 상세 페이지 어디에도 표시되지 않습니다(과거 자유 블록 체계용 필드로, 현재는 사용되지 않습니다).
- "상세 페이지 보충 항목" — 여기에 overview/purpose/role/tools 키로 내용을 채우면, 위 기본 정보(제작 의도/기여도/설명/Tools) 대신 이 내용이 우선 사용됩니다. 채우지 않으면 위 기본 정보가 그대로 쓰입니다.

## 13. 향후 계획 관리 (`/admin/future-plans`)

→ 홈페이지 "향후 추진 계획" 구역.

- 제목 / 요약 / 세부 계획 / 기대 효과 / 진행 상태 — 카드 내용. 진행 상태(예정/준비중/진행중/완료) 배지가 카드에 표시됩니다.
- 순서(order) 기준 **상위 3개만** 카드로 보여줍니다. 4개 이상 등록해도 나머지는 안 보이니, 정말 보여줄 3개만 위로 올려두세요(↑↓ 또는 각 항목의 "노출" 체크박스 활용).

→ 홈페이지 "FAQ" 구역.

## 15. 마무리 화면 관리 (`/admin/closing`)

→ 홈페이지 맨 마지막 "마무리 화면".

- 마무리 문구 / 이름 / 직무 / 소속 / 배지 문구 — 마지막 화면 텍스트.
- 배경 이미지 / 배경 영상(선택) — 마지막 화면 배경.
- ⚠️ "공개 상태" 드롭다운은 현재 반영되지 않습니다(항상 보임).

---

## 16. 사이트 설정 (`/admin/settings`)

- 사이트 제목 — 브라우저 탭 제목으로 실제 반영됩니다.
- 강조 색상(주황/파랑) — 사이트 전체 포인트 색상으로 실제 반영됩니다.
- 움직임 감소 설정 지원 — ⚠️ 현재 이 체크박스 값과 관계없이, 방문자 OS의 "동작 줄이기" 설정은 항상 자동으로 존중됩니다(꺼도 켜도 결과가 같습니다).
- ⚠️ "화면 영역 노출 및 순서" — 체크박스와 ↑↓ 화살표 모두 **현재 홈페이지에 반영되지 않습니다.** 홈페이지 7개 구역은 위 "0. 사이트 전체 그림"에 적은 순서로 코드에 고정되어 있어서, 여기서 순서를 바꾸거나 노출을 꺼도 실제 화면은 그대로입니다.

---

## 17. 휴지통 (`/admin/trash`)

삭제한 프로젝트 등을 복구하거나 완전히 삭제합니다. "복구"를 누르면 원래 목록으로 돌아가고, "완전 삭제"는 되돌릴 수 없습니다.

---

## 18. 백업 (`/admin/backup`)

"전체 콘텐츠 내려받기(JSON)"로 현재 모든 콘텐츠를 파일 하나로 내려받습니다. 날짜별로 안전한 곳에 보관해 두면, 문제가 생겼을 때 개발 담당자가 이 파일로 되돌릴 수 있습니다.

---

## 정리 — 지금 당장 실제로 "켜고 끌 수 있는" 공개 설정은 이것뿐입니다

- 프로젝트: 편집 화면의 **"공개 가능 여부(클라이언트 승인)"** — 유일하게 확실히 작동하는 프로젝트 노출 스위치.
- 목록형 항목(성장과정 연도, 역량, 향후 계획, FAQ) 각각의 **"노출" 체크박스** — 항목 하나만 숨길 때 사용.
- 사이트 설정의 **강조 색상**, **사이트 제목** — 실제로 반영됩니다.
