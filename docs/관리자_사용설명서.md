# 관리자 화면 사용설명서

이 문서는 개발 지식이 없어도 포트폴리오 내용을 직접 수정할 수 있도록 안내합니다.
번호 순서대로 따라 하면 됩니다. (현재 문서는 화면 캡처 없이 텍스트로 제공되며,
각 단계에 실제 화면의 메뉴명과 버튼 문구를 그대로 표기했습니다.)

관리자 화면 주소: `배포 주소/admin` (예: `https://your-domain.vercel.app/admin`)

---

## 1. 관리자 화면 로그인 방법

1. 브라우저에서 `배포 주소/admin` 으로 접속합니다.
2. 자동으로 로그인 화면(`/admin/login`)으로 이동합니다.
3. "비밀번호" 입력란에 관리자 비밀번호를 입력합니다. (배포 담당자에게 문의)
4. "로그인" 버튼을 누르면 대시보드 화면으로 이동합니다.
5. 30분 동안 아무 작업이 없으면 자동으로 로그아웃되며, 다시 로그인해야 합니다.
6. 작업을 마치면 왼쪽 메뉴 하단의 "로그아웃"을 눌러 안전하게 종료하세요.

---

## 2. 자기소개 수정방법

1. 왼쪽 메뉴에서 "프로필 관리"를 클릭합니다.
2. "짧은 자기소개", "긴 자기소개" 입력란의 내용을 원하는 문구로 바꿉니다.
3. "대표 문구" 도 필요하면 함께 수정합니다.
4. 화면 아래 "저장하기" 버튼을 누릅니다. 저장이 끝나면 하단에 "마지막 저장: (시간)" 이 표시됩니다.

---

## 3. 시작 화면 문구 수정방법

1. 왼쪽 메뉴에서 "시작 화면 관리"를 클릭합니다.
2. "핵심 문구" 입력란에서 첫 화면의 큰 글자 문구를 수정합니다. (줄바꿈으로 여러 줄 가능)
3. "보조 문구" 에 짧은 설명 문장을 입력합니다.
4. 이름/직무/소속/입사 연도 표기, 배지 문구(예: "2026년 특별진급 포트폴리오")도 필요 시 수정합니다.
5. "저장하기" 를 누릅니다.
6. 화면 상단의 "공개 상태" 를 "공개" 로 바꿔야 방문자에게 노출됩니다. (작성 중에는 "작성 중" 상태로 두세요.)

---

## 4. 프로필 사진 교체방법

1. "프로필 관리" 메뉴로 이동합니다.
2. "프로필 사진" 항목의 "파일 선택 / 교체" 버튼을 클릭합니다.
3. 컴퓨터에서 사진 파일(JPG, PNG, WebP, AVIF 중 하나, 20MB 이하)을 선택합니다.
4. 업로드가 끝나면 미리보기가 바로 바뀝니다.
5. 사진 아래 "대체 설명(alt) 입력" 칸에 사진에 대한 간단한 설명을 입력하면 접근성에 도움이 됩니다.
6. "저장하기" 를 누릅니다.

같은 방식으로 "촬영 현장 사진"도 여러 장 추가할 수 있습니다. ("+ 현장 사진 추가" 버튼)

---

## 5. 대표 영상 교체방법

1. "시작 화면 관리" 메뉴로 이동합니다.
2. "대표 영상 (선택)" 항목에서 "파일 선택 / 교체"를 눌러 영상 파일(MP4, WebM, MOV 중 하나, 300MB 이하)을 업로드합니다.
3. 영상이 재생되지 않는 환경을 대비해 "대표 이미지" 도 함께 등록해 두세요. 영상이 없으면 이 이미지가 대신 보여집니다.
4. "저장하기" 를 누릅니다.

마무리 화면의 배경 영상/이미지는 "마무리 화면 관리" 메뉴에서 같은 방식으로 교체합니다.

---

## 6. 프로젝트 추가방법

1. 왼쪽 메뉴에서 "프로젝트 관리"를 클릭합니다.
2. 화면 오른쪽 위 "+ 새 프로젝트" 버튼을 클릭합니다.
3. 자동으로 새 프로젝트 편집 화면으로 이동합니다.
4. 프로젝트명, 브랜드명, 작업 분야, 제작 목적, 담당 역할 등 정보를 입력합니다.
5. 화면 아래 "저장하기" 를 눌러 저장합니다.

---

## 7. 프로젝트 내용 수정방법

1. "프로젝트 관리" 메뉴에서 목록 중 수정할 프로젝트의 제목(또는 "편집")을 클릭합니다.
2. 필요한 항목을 수정합니다. (제목, 브랜드명, 작업 분야, 목적, 역할, 설명, 사용 도구 등)
3. "대표 이미지", "미리보기 영상", "최종 영상" 은 각각의 업로드 버튼으로 교체합니다.
4. 화면 아래쪽 "대표 프로젝트 상세 사례 항목" 에서 프로젝트 개요, 기존 상황, 제작 목적, 담당 역할,
   기획 및 제작 과정, 주요 판단, 사용 도구, 최종 결과물, 성과 및 의미, 이후 활용 가능성 항목을
   필요한 만큼 추가하고 내용을 채웁니다. 필요 없는 항목은 삭제하면 됩니다.
5. 다 작성했으면 "저장하기" 를 누릅니다.

---

## 8. 프로젝트 삭제 및 복구방법

**삭제하기**
1. "프로젝트 관리" 목록에서 삭제할 프로젝트 오른쪽의 "삭제" 를 클릭합니다.
2. "정말 삭제할까요?" 확인 문구가 뜨면 "예" 를 클릭합니다.
3. 프로젝트는 즉시 완전히 사라지지 않고 "휴지통" 으로 이동합니다.

**복구하기**
1. 왼쪽 메뉴에서 "휴지통"을 클릭합니다.
2. 복구할 항목 옆의 "복구" 버튼을 클릭하면 원래 목록으로 되돌아갑니다.
3. 완전히 삭제하려면 "완전 삭제" 를 클릭 후 확인합니다. (이 작업은 되돌릴 수 없습니다.)

---

## 9. 사진 여러 장 추가방법

1. 프로젝트 편집 화면에서 "상세 이미지 (갤러리)" 항목까지 스크롤합니다.
2. "이미지 추가" 버튼으로 사진을 한 장씩 업로드합니다. 여러 번 반복하면 여러 장을 추가할 수 있습니다.
3. 상세 사례 항목 안의 "이미지" 영역에서도 같은 방식으로 여러 장을 추가할 수 있습니다.
4. "보정 전후 비교" 영역에서는 "+ 보정 전후 비교 추가" 로 보정 전/후 사진 쌍을 등록할 수 있습니다.
5. 마지막에 "저장하기" 를 잊지 마세요.

---

## 10. 영상 추가방법

1. 프로젝트 편집 화면에서 "미리보기 영상" 또는 "최종 영상" 의 업로드 버튼을 클릭합니다.
2. 컴퓨터에 저장된 영상 파일을 선택합니다. (MP4, WebM, MOV, 최대 300MB)
3. 대표 프로젝트 상세 사례 항목 안에서도 "영상" 영역에서 같은 방식으로 추가할 수 있습니다.
4. 영상 용량이 너무 크면 업로드가 거부됩니다. 이 경우 영상을 압축하거나, YouTube/Vimeo 에 올린 뒤
   개발 담당자에게 외부 영상 주소 입력 기능 추가를 요청하세요.

---

## 11. 프로젝트 순서 변경방법

1. "프로젝트 관리" 목록에서 각 프로젝트 왼쪽의 위/아래 화살표(↑ ↓)를 클릭합니다.
2. 클릭할 때마다 순서가 즉시 바뀌고 저장됩니다. (별도 저장 버튼이 필요 없습니다.)
3. 성장과정, 역량, 성과, 협업 평가, 향후 계획 등 다른 목록형 메뉴도 동일한 방식으로 순서를 바꿀 수 있습니다.

---

## 12. 성과 수치 수정방법

1. 왼쪽 메뉴에서 "성과 관리"를 클릭합니다.
2. 항목의 "수치", "단위", "설명 / 근거", "기준일", "출처" 를 입력합니다.
3. 확인되지 않은 수치는 비워 두세요. 값이 비어 있으면 공개 화면에 자동으로 표시되지 않습니다.
4. 실제 수치를 입력한 뒤에는 반드시 "공개 화면에 노출" 체크박스를 켜야 방문자에게 보입니다.
5. "저장" 버튼을 클릭합니다.

---

## 13. 공개 및 비공개 설정방법

**화면 영역 단위 공개/비공개**
1. "시작 화면 관리", "핵심 철학 관리" 등 각 메뉴 상단의 "공개 상태" 를 "작성 중 / 검토 중 / 공개 / 비공개" 중 선택합니다.
2. 방문자에게 보이려면 반드시 "공개" 로 설정해야 합니다.

**프로젝트 단위 공개/비공개**
1. 프로젝트 편집 화면에서 "공개 가능 여부 (클라이언트 승인)" 를 켜야 합니다. (꺼져 있으면 절대 공개 화면에 나타나지 않습니다.)
2. "공개 상태" 도 함께 "공개" 로 설정합니다.

**화면 영역 전체 노출 여부**
1. 왼쪽 메뉴 "사이트 설정" 에서 각 화면 영역의 "노출" 체크박스를 켜거나 끕니다.
2. 같은 화면에서 위/아래 화살표로 화면 영역이 보여지는 순서도 바꿀 수 있습니다.

---

## 14. 게시 전 미리보기 방법

1. 왼쪽 메뉴 하단의 "공개 화면 보기 ↗" 를 클릭하면 새 탭에서 실제 공개 화면이 열립니다.
2. 컴퓨터 화면에서는 브라우저 창을 좁게 줄여 태블릿/모바일 화면도 확인할 수 있습니다.
3. "공개 상태" 를 아직 "공개" 로 바꾸지 않은 항목은 이 미리보기에도 나타나지 않으므로,
   내용을 다 확인한 뒤 상태를 "공개" 로 바꾸고 다시 한번 확인하는 것을 권장합니다.

---

## 15. 자료 백업방법

1. 왼쪽 메뉴에서 "백업"을 클릭합니다.
2. "전체 콘텐츠 내려받기 (JSON)" 버튼을 클릭하면 현재 모든 콘텐츠가 담긴 파일이 다운로드됩니다.
3. 이 파일은 안전한 곳(회사 드라이브, 개인 클라우드 등)에 날짜별로 보관해 두세요.
4. 복원이 필요하면 개발 담당자에게 파일을 전달해 `content/site-content.json` 으로 교체해 달라고 요청하세요.

---

## 16. 관리자 비밀번호 변경방법

로컬(설치형) 모드에서는 비밀번호가 서버의 환경변수 파일(`.env`)에 저장되어 있습니다.

1. 서버가 설치된 컴퓨터 또는 배포 플랫폼(Vercel 등)의 환경변수 설정 화면을 엽니다.
2. `ADMIN_PASSWORD` 값을 원하는 새 비밀번호로 바꿉니다.
3. 서버를 재시작합니다. (Vercel의 경우 재배포하면 자동 적용됩니다.)
4. 이후부터는 기존 비밀번호로 로그인할 수 없고, 새 비밀번호로만 로그인됩니다.

실제 서비스로 운영할 때(Supabase 연동 후)는 Supabase Authentication 화면에서
관리자 계정의 비밀번호를 직접 변경할 수 있습니다.

---

## 참고: 이 외에 자주 쓰는 메뉴

- **성장과정 관리**: 연도별(2024/2025/2026) 업무 확장 스토리를 추가·수정·삭제·순서 변경합니다.
- **역량 관리**: 주요 업무 역량 5가지 항목을 관리합니다.
- **인공지능 활용 관리**: 생성형 인공지능 제작 흐름 단계와 사용 도구(Flow AI, Higgsfield AI 등)를 관리합니다.
- **조직 기여 관리**: 팀/조직에 기여한 사례를 관리합니다.
- **협업 평가 관리**: 협업 대상, 협업 과정, 협업 평가/후기를 관리합니다. 작성자 이름과 직책은
  공개 여부를 각각 선택할 수 있습니다.
- **특별진급 적합성 관리** / **향후 계획 관리**: 특별진급 관련 핵심 문구와 이후 실행 계획을 관리합니다.

문의사항이나 새로운 기능이 필요하면 개발 담당자에게 이 문서와 함께 요청 내용을 전달해 주세요.
